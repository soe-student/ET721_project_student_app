About EduHub

EduHub is a Student Learning Management App built for the ET721 course project. It provides students with a unified platform to manage academic tasks, share ideas, and organise study notes — all in one secure, personal space.

Features

🔐 Secure Login

Session-based auth with hashed passwords (Werkzeug).

📋 Task Manager

Create, categorise, complete, and delete tasks.

✍️ Blog

Publish posts, like, and comment on others' writing.

📎 Notes

Upload images/PDFs, organised by subject with preview.

Tech Stack: Python · Flask · SQLite · Flask-SQLAlchemy · Flask-Login · HTML/CSS · JavaScript
